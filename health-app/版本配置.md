# Fitters 版本配置

本项目当前按 `Fitters开发说明文档.docx` 的第一阶段技术基线实现。

## 后端

- Node.js: 20 LTS
- TypeScript: 5.x
- Express: 4.x
- Prisma: 5.x
- 数据库: PostgreSQL 14+，Docker Compose 默认使用 `postgres:16-alpine`
- 鉴权: JWT
- 密码哈希: bcrypt

## 前端

- Vue: 3.5.x
- Vite: 5.4.x
- Node.js: 20 LTS

## AI 服务

- Python: 3.11-slim Docker 镜像
- Flask: 3.0.3

## 容器化

- Docker Desktop: 建议使用稳定版最新版
- Docker Compose: 使用 Docker Desktop 自带版本即可

## 本地开发建议

1. 后端依赖使用 `npm install` 安装。
2. 后端数据库连接写在 `backend/.env`，可从 `backend/.env.example` 复制。
3. 数据库结构变更必须修改 `backend/prisma/schema.prisma` 并提交 Prisma migration。
4. Docker Compose 会通过 `DATABASE_URL` 连接 `postgres` 服务，并在后端容器启动时执行 `prisma migrate deploy`。
5. 如需初始化演示数据，可在后端目录执行 `npm run prisma:seed`。
